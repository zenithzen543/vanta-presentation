# Thorn & Furrow — interview presentation

An original **heirloom seed catalog** on Next.js + Sanity. Built to show marketing-CMS work **without cloning vanta.com** and without NDA client source.

This is a print catalog on the web: masthead, featured variety, sowing table, indexed list, journal, workshops. There is no 2×3 SaaS feature grid.

## Run

```bash
npm run seed
npm run dev
```

- Catalog: http://localhost:3000
- Studio: http://localhost:3000/studio

Then follow [presentation/DEMO.md](presentation/DEMO.md).

Old Cove/Vanta documents are removed when you seed. Studio desk is **The farm**: catalog homepage, settings, varieties, journal, workshops.
